WEBSITE CÁ NHÂN - HƯỚNG DẪN

1. Mở file index.html để xem website trên máy tính.
2. Sửa "Tên Của Bạn" trong index.html thành tên của bạn.
3. Sửa nội dung giới thiệu, dự án và liên hệ theo ý muốn.
4. Có thể thay các ô hình ảnh trong phần #gallery bằng ảnh riêng.

ĐƯA WEBSITE LÊN GITHUB PAGES MIỄN PHÍ

1. Tạo tài khoản tại https://github.com/
2. Tạo repository có tên:
   USERNAME.github.io
   (USERNAME là tên tài khoản GitHub của bạn)
3. Upload index.html, style.css và script.js lên repository.
4. Vào Settings -> Pages.
5. Chọn Deploy from a branch -> main -> /(root) -> Save.
6. Sau khi GitHub triển khai xong, website sẽ ở:
   https://USERNAME.github.io

LƯU Ý:
- Website này không cần cài server.
- Phần form liên hệ hiện chỉ là demo, chưa gửi email thật.
- Có thể dùng tên miền riêng sau này nếu muốn.
